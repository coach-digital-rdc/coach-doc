# L'écran d'accueil

L'écran d'accueil donne accès aux principales fonctions de l'application.

![Écran d'accueil](/img/rdc/accueil.png)

## Menu horizontal

En haut de l'écran, le menu horizontal propose :

- **Nouvelle observation** : commencer une observation de classe ;
- **Manuel d'utilisation** : consulter le manuel de l'outil d'observation, même sans connexion ;
- **Séances en attente** : voir les enseignants dont l'entretien reste à faire ;
- **Statistiques** : consulter les statistiques des enseignants ;
- **Changer d'établissement** et **Se déconnecter**.

## Les enseignants

Sous le menu, la liste des enseignants de l'établissement indique, pour chacun, le nombre d'observations et la date de la dernière. Touchez un enseignant pour ouvrir son profil et commencer une observation.

### Ajouter un enseignant

1. Touchez « Ajouter un enseignant ».
2. Renseignez le formulaire, avec exactitude : ces informations permettent de distinguer les enseignants.
   - **Prénom et nom** ;
   - **Photo**, facultative, pour reconnaître plus facilement l'enseignant ;
   - **Date de naissance** ;
   - **Matricule**, facultatif ;
   - **Discipline principale**, parmi les disciplines du secondaire (français, mathématiques, physique, chimie, biologie, etc.).
3. Touchez « Ajouter l'enseignant » : il apparaît dans la liste.

:::tip
Si certaines informations manquent, saisissez l'essentiel : le profil pourra être complété plus tard.
:::

### Modifier un enseignant

1. Touchez l'enseignant dans la liste.
2. Dans son profil, touchez « Modifier l'enseignant ».
3. Corrigez les informations, puis touchez « Enregistrer ».

## Barre du bas

La barre du bas donne accès à l'**Accueil**, aux **Cercles** d'apprentissage et aux séances **En attente**.

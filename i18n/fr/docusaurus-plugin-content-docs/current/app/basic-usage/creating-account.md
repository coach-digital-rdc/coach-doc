# Se connecter

L'observateur se connecte avec l'adresse e-mail ou le numéro de téléphone enregistré par l'administration.

1. **Saisir son identifiant** : sur l'écran d'accueil, saisissez votre adresse e-mail ou votre numéro de téléphone, puis touchez « Se connecter ».
2. **Saisir le code reçu** : un code à 6 chiffres vous est envoyé. Saisissez-le, puis touchez « Vérifier ». Si vous ne le recevez pas, touchez « Renvoyer le code ».
3. **Choisir l'établissement** : la liste des établissements s'affiche ; touchez celui où vous travaillez.

Si votre identifiant n'est pas reconnu, vous pouvez créer un compte avec « Créer un compte » : renseignez votre prénom, votre nom, votre adresse e-mail et votre téléphone, de façon exacte, puis touchez « Créer le compte ». En cas de difficulté, adressez-vous à l'administrateur de la plateforme.

**Une fois connecté**, vous arrivez à l'écran d'accueil, présenté à la page suivante. La connexion est conservée : vous n'aurez pas à la refaire à chaque ouverture de l'application.

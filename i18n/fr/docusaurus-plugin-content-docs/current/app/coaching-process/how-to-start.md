# Commencer l'entretien

Après l'observation de classe, l'observateur et l'enseignant se retrouvent pour l'entretien. Il peut commencer de deux façons.

## Juste après l'observation

À la fin de l'observation, touchez « Commencer l'entretien ».

:::caution Séance inachevée
Si vous revenez à l'accueil sans faire l'entretien, la séance reste inachevée. Convenez rapidement d'un moment avec l'enseignant pour la terminer.
:::

## Pour une séance inachevée

Les enseignants dont l'entretien reste à faire apparaissent dans « Séances en attente », accessible depuis le menu horizontal ou la barre du bas.

1. Touchez l'enseignant pour reprendre la séance.
2. Relisez le résumé de l'observation, puis commencez l'entretien.

# Coter les comportements

La grille d'observation reprend l'outil papier : six sous-domaines et 30 comportements, numérotés de 1.1 à 4.6. Chaque sous-domaine s'affiche comme un bloc ; il est coché lorsque tous ses comportements sont cotés.

![Grille d'observation](/img/rdc/grille-observation.png)

## Les réponses

Chaque comportement propose les réponses de l'outil papier :

- **Oui / Non** pour 1.1 et 1.3 ;
- **Faible / Moyen / Élevé** pour les autres comportements ;
- **N/A** en plus, pour 1.2, 1.3, 2.1.3, 3.2.1 et 3.2.3, lorsque le comportement ne peut pas être observé pendant la séance.

Touchez la réponse qui correspond à ce que vous avez observé. Vous pouvez la changer tant que l'observation n'est pas confirmée.

## L'aide de chaque comportement

Le bouton **?** à côté d'un comportement ouvre son aide : la description des niveaux Faible, Moyen et Élevé tirée du manuel d'utilisation, avec des exemples. Consultez-la en cas d'hésitation.

## Points à aborder

Sous la grille, notez les points que vous souhaitez aborder avec l'enseignant pendant l'entretien. Le compteur en bas de l'écran indique le nombre de sous-domaines cotés ; le bouton « Terminer l'observation » devient actif lorsque les six sont cotés.

## Confirmer l'observation

L'écran de résumé reprend, sous-domaine par sous-domaine, la réponse donnée à chaque comportement. Vérifiez-les, puis touchez « Confirmer », ou « Modifier » pour revenir à la grille.

# Après l'observation

Une fois l'observation confirmée, deux choix sont proposés :

- **Commencer l'entretien** avec l'enseignant tout de suite ;
- **Revenir à l'accueil**, pour faire l'entretien plus tard.

Sans entretien, la séance reste **inachevée** : l'enseignant apparaît dans « Séances en attente » jusqu'à ce que l'entretien soit fait.

# Données de l'enseignant

Au fil des observations et des entretiens, l'application constitue le dossier de chaque enseignant. Ce dossier aide l'observateur à préparer ses entretiens et à suivre la progression de l'enseignant.

Le profil de l'enseignant présente deux types d'informations : les séances précédentes et les statistiques.

## Les séances précédentes

Pour un enseignant déjà observé, le profil liste les séances passées : réponses de l'observation, actions convenues pendant l'entretien et photos jointes.

## Les statistiques

Les statistiques sont disponibles **après trois séances complètes** avec l'enseignant. Elles montrent l'évolution de l'enseignant dans chaque sous-domaine, séance après séance, et permettent de repérer les progrès ou les reculs.

# Consulter les séances précédentes

1. **Ouvrir le profil de l'enseignant** : sur l'écran d'accueil, touchez l'enseignant. Ses séances sont listées de la plus récente à la plus ancienne, avec leur date et l'appréciation générale.

2. **Choisir une séance** : touchez la séance à consulter.

   ![Séance précédente](/img/rdc/seance-precedente.png)

3. **Consulter le détail** :
   - **Observation** : le résumé des réponses données pendant l'observation de classe ;
   - **Entretien** : les actions convenues avec l'enseignant, en texte ou en photo. Si l'entretien n'a pas encore eu lieu, ce choix permet de le commencer.

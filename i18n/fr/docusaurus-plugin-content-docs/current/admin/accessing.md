# Présentation de l'administration

L'administration (interface web) sert au PAAF, au SERNAFOR et aux responsables désignés pour gérer les données de Coach Digital RDC. Elle permet de :

- consulter les séances d'observation réalisées par les observateurs ;
- suivre les résultats au niveau de l'établissement, de la sous-PROVED, de la PROVED, de la province ou du pays\* ;
- gérer la grille d'observation (sous-domaines et comportements) ;
- gérer les établissements, les observateurs et la hiérarchie territoriale.

\*_Les données visibles dépendent du périmètre attribué à chaque utilisateur : un utilisateur rattaché à une province ne voit que les établissements de cette province._

## Se connecter

Ouvrez l'adresse de l'administration communiquée par le projet, saisissez votre adresse e-mail et touchez « Recevoir un code de connexion ». Saisissez le code reçu par e-mail, puis « Vérifier le code ».

L'administration s'affiche en français ; le menu en bas de la barre latérale permet de passer en anglais.
